# PocketRule 1.17.0

Implemented:
- Add money to the active plan.
  - New "Add money to this plan" action.
  - Added money is distributed using the plan's existing category percentages.
  - Category budgets and total plan income update in place.
  - Linked history entry stays synchronized.
- One-step onboarding.
  - Currency is automatically selected from device region/locale, with timezone fallback.
  - Currency can still be changed manually.
  - Starting Rule and reminders are now on the same setup screen.
